【一】运行需要准备什么
----------------------------------------------------------
1. 操作系统：Windows 10 / 11
2. Python 3.10 ~ 3.14（唯一需要预装的软件）
   - 官网下载：https://www.python.org/downloads/
   - 安装时务必勾选「Add Python to PATH」
3. 磁盘空间：约 1 GB（存放运行环境与你的数据）
4. 首次启动需要联网下载依赖组件（约 3~10 分钟，
   取决于网速）；之后永久离线可用。

【二】四个启动脚本的作用
----------------------------------------------------------
「一键配置网络环境.bat」—— 只做一件事：联网下载安装全部运行
   依赖（首次约 3~10 分钟），并自动在官方源 / 清华镜像间切换。
   想提前装好环境、或首次启动报网络错误时，双击它即可；
   装完后日常使用不需要再点它。

「滴鱼简历助手.bat」—— 日常主入口（浏览器版）。
   若环境还没配置，它会自动完成上面的安装过程，
   然后启动本地服务并自动打开浏览器。
   手机扫码直传已默认加载，可在首页用开关随时关闭。
   使用期间请保持黑色窗口开启（它就是服务本体）。

「滴鱼简历助手-桌面版.bat」—— 独立桌面窗口版（不依赖浏览器）。
   功能与浏览器版完全一致，数据完全共用，
   适合不喜欢浏览器标签页的用户；同样支持首页扫码直传开关。

「滴鱼简历助手-局域网直传.bat」—— 兼容旧版的强制开启入口。
   一般无需再单独运行；主入口和发布版 EXE 已默认具备相同功能。

提示：三个「启动」脚本操作的是同一份数据；
      「一键配置网络环境.bat」只在装环境时用一次。

【三】首次启动流程
----------------------------------------------------------
1. 双击「滴鱼简历助手.bat」
   （也可先双击「一键配置网络环境.bat」提前装好依赖）
2. 黑色窗口会自动创建运行环境并安装依赖，
   期间出现英文进度属正常现象 —— 请勿关闭窗口！
3. 完成后浏览器自动打开 http://127.0.0.1:8000
   （若没打开，手动在浏览器输入该地址即可）
4. 按页面引导完成初始化向导。

【四】常见问题与解决办法
----------------------------------------------------------
Q1 提示「Python not found in PATH」？
   → 未安装 Python 或没勾选 Add to PATH。
     重新安装 Python 并勾选该选项后重开窗口。

Q2 安装依赖时报红字 / 失败 / 长时间不动？
   → 多为网络问题。处理顺序：
     ① 关闭代理/加速器后重试；
     ② 直接重新双击启动脚本（会跳过已完成步骤；
        现在默认源失败会自动改用清华镜像重试）；
     ③ 或直接双击「一键配置网络环境.bat」重新补装依赖；
     ④ 手动补装：在本文件夹打开 cmd，执行
        .venv\Scripts\python.exe -m pip install -r requirements.txt

Q3 浏览器没有自动打开，或显示无法访问？
   → 黑色窗口必须保持开启（它就是服务本体）；
     启动后等约 8 秒再刷新浏览器；
     仍不行就手动访问 http://127.0.0.1:8000

Q4 提示端口被占用？
   → 脚本会自动在 8000 ~ 8010 之间寻找空闲端口并提示新地址，
     用提示里的地址访问即可。

Q5 手机扫码 / 局域网访问要求输入配对码？
   → 这是安全设计。配对码显示在：
     ① 启动时的黑色窗口里；② 首页二维码下方。
      输入一次后该设备 30 天内免输。
     若二维码区域显示已关闭，请在首页右上角打开「扫码直传」开关。

Q6 杀毒软件 / Windows 提示拦截？
   → 本程序开源且不联网上传数据，选择
     「允许运行」/「添加信任」即可。

Q7 第一次上传证书识别很慢？
   → 首次识别需加载 OCR 引擎，之后会明显变快。
     扫描件模糊可点「旋转重试」或「AI 整理」（需配 AI）。

Q8 想彻底重置成全新状态？
   → 关闭黑色窗口后，删除本目录下的
     「data」文件夹，再启动即回到初始向导。

Q9 数据会传到网上吗？安全吗？
   → 全部数据保存在本目录的 data 文件夹内，
     程序本身不上传任何信息。
     只有当你主动配置 AI 并使用 AI 功能时，
     相关文字才会发送到你自己填写的接口商。
