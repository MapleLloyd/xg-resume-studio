# Changelog

本项目的所有显著变更记录在此文件中。格式参考 [Keep a Changelog](https://keepachangelog.com/)，版本遵循语义化版本。

## [Unreleased]

### Fixed
- 发布版 EXE 现在直接支持手机扫码直传，不再依赖发布包中不存在的 BAT 脚本
- 扫码直传默认开启，并可在首页持久化开关；关闭后立即拒绝所有非本机访问

## [0.1.0] - 2026-08-25

### Added
- 上传材料（图片/PDF/Word）自动 OCR 与规则提取「获奖情况」「任职情况」，弹窗确认后入库
- 可选接入 OpenAI 兼容大模型：AI 整理、AI 助手「小点」对话与简介改写回写
- 获奖与任职条目管理，支持佐证文件上传与级联清理；进行中状态标记（至今）
- 个人资料页：基本信息/证件照/教育/论文/项目/技能，1.5 秒自动保存
- 首次启动向导：账户命名、小点头像、AI 配置（服务商预设 + 测试连接）、示例数据一键载入
- 四套场景化 A4 简历模板（求职/保研/晋升/评优）+ 主题色 + 三档密度 + 模块显隐排序
- 打印存 PDF、简历 Word / 个人介绍 Word 导出（内存生成不落盘）
- 多账户隔离（虚拟账户）与手机扫码局域网直传（令牌绑定账户）
- 启动自动滚动备份数据库（保留最近 20 份）
- 安全加固：局域网模式配对码门卫、CSRF Origin 校验、API Key 掩码回显
