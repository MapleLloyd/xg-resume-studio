# Changelog

本项目的所有显著变更记录在此文件中。格式参考 [Keep a Changelog](https://keepachangelog.com/)，版本遵循语义化版本。

## [1.1.0] - 2026-08-27

### Added
- 服务端 PDF 导出：`/resume.pdf` 用 reportlab 生成标准 A4 PDF（中英文、跟随简历版本与模块），不再依赖浏览器打印
- 多份简历版本（#2）：每账户至少一个「默认简历」版本；每版本独立记忆模板/主题色/密度/模块显隐排序/个人简介/自我评价，获奖、任职、教育等条目全局共享；「版本管理」面板新建/重命名/删除/编辑
- 简历中英文切换（#4）：简历预览页一键切换文案语言，模板、PDF、Word 导出同步；内容数据保持用户填写的中文
- 个人资料新增「自我评价」（#7）：性格/态度标签 + 自由文本，作为简历独立模块可显隐排序
- 应用内更新日志页 `/changelog`（#5）：本地展示 CHANGELOG，不联网
- 小点 AI 流式回复（#11）：SSE 打字机输出、可随时停止、服务端超时自动重试一次；system prompt 声明用户数据只读、忽略改身份指令；单次回复 12k token 截断
- 局域网 IP 手动覆盖（#14）：首页可手动指定私网 IPv4，自动选错时立即生效并提示
- 上传体验（#12）：PDF 返回页数、识别失败给出可操作诊断（扫描件/方向/文字层/清晰度/引擎）；首页上传区补充 20MB/50 页限制与等待引导
- 应用内安装包：Inno Setup 安装版（#6），开始菜单/桌面快捷方式、卸载时询问是否保留数据

### Fixed
- 局域网手机扫码直传在发布版 EXE 中可用：主程序与桌面版统一监听 `0.0.0.0`；前端新增可持久化的开关，且默认关闭（#15），避免公网/不可信网络下无意暴露
- 局域网 IP 选择不再受 VPN/代理/虚拟网卡影响：枚举本机所有 IPv4，排除 `100.x`（CGNAT/Tailscale）与 `198.18.x`（基准测试/Meta 隧道）网段，优先选择与默认网关同网段的私网地址
- 手机令牌从查询参数 `?t=xxx` 改为路径 `/m/xxx`，避免 iOS/部分相机扫码时截断 `?` 后内容
- 局域网 IP 二维码默认返回 PNG（相机识别最稳），同时支持 `?fmt=svg` 兜底
- 资源文件加版本号 `?v=…`，浏览器升级后不再复用旧 CSS/JS 缓存
- 安全加固（#9）：uid Cookie 加 HMAC 签名校验；敏感操作（重命名/删除账户）要求目标为当前账户；新增「忘记 Key」一键清除本地 API Key；README 改为「轻量档案切换，不是登录系统」
- 数据与性能（#10）：SQLite 启用 WAL + busy_timeout，降低并发锁库；上传单文件 ≤20MB、PDF ≤50 页并中文提示；修复老库重建 profile 表时遗漏 hometown/self_eval/self_tags 列的问题
- 修复多版本接口中 `self_tags` 列表未序列化的保存错误

### Changed
- 打包流水线：build.yml 冒烟测试加强为「HTTP 200 + 页面含品牌名 + LAN 监听器存在」；新增 Inno Setup 安装包构建并在 Release 同时附上绿色版 zip 与安装版 exe
- `滴鱼简历助手-局域网直传.bat` 改为「兼容旧版的强制开启入口」文档说明（功能已并入主入口），三个启动 bat 全部支持 `0.0.0.0` 监听

### Internal
- 补 6 个局域网测试 + 多版本/PDF/手动 IP 等新功能测试（现共 40+ 个用例全过）
- `requirements.txt` 新增 `reportlab>=4.0`；`requirements-dev.txt` 新增 `opencv-python-headless>=5.0` 与 `httpx>=0.27` 显式声明
## [0.1.0] - 2026-08-25

### Added
- 上传材料（图片/PDF/Word）自动 OCR 与规则提取「获奖情况」「任职情况」，弹窗确认后入库
- 可选接入 OpenAI 兼容大模型：AI 整理、AI 助手「小点」对话与简介改写回写
- 获奖与任职条目管理，支持佐证文件上传与级联清理；进行中状态标记（至今）
- 个人资料页：基本信息/证件照/教育/论文/项目/技能，1.5 秒自动保存
- 首次启动向导：账户命名、小点头像、AI 配置（服务商预设 + 测试连接）、示例数据一键载入
- 四套场景化 A4 简历模板（求职/保研/晋升/评优）+ 主题色 + 三档密度 + 模块显隐排序
- 打印存 PDF、简历 Word / 个人介绍 Word 导出（内存生成不落盘）
- 多账户隔离（虚拟账户）与手机扫码局域网直传（令牌绑定账户）
- 启动自动滚动备份数据库（保留最近 20 份）
- 安全加固：局域网模式配对码门卫、CSRF Origin 校验、API Key 掩码回显
